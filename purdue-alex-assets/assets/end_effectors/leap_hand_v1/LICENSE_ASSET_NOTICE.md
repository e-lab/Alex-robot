# LEAP Hand V1 asset licensing notice

The official LEAP Hand CAD page classifies the downloadable CAD and URDF
files as **CC BY-NC-SA**, but does not state a Creative Commons version. This
repository therefore applies that conservative, version-unspecified
classification to the imported URDF and STL files and does not infer extra
permissions.

Upstream is internally inconsistent: the `LEAP_Hand_Sim` repository root at
the pinned revision contains an MIT license, copied verbatim as
`LICENSE_LEAP_HAND_SIM_MIT.txt`; the official LEAP API documentation also
distinguishes MIT-licensed code from CC BY-NC-SA CAD, while its current root
license differs again. These facts are recorded rather than resolved locally.

Official statement: https://v1.leaphand.com/leap_cad
